## 一、核心分层（识别层 vs 规则层，不变）

OCR 干两件事：**识别** + **回填**。规则引擎只消费它认识的字段。

- **识别层**：按 LF1234 清单，识别化验单/报告上**所有关注项目及异常值**（全量识别，多项次要项可低优先级）。
- **规则层**（后端 rule_engine.py，**保持不动**）：只消费后端已有字段。
- **后端无字段的项目** → 识别后回填到对应卡片的「其他异常值」文本区，**仅记录、不进规则**（供医生参考）。

> LF1234 说的「识别所有异常值」完全能做到，且**不需要改后端**。
> 只有当某个新项目（如尿酸、BNP）**要参与自动规则判断**时，才需要扩充后端字段+规则——这属于另一个决策，见第七节。

## 三、判读依据（LF1234 新增，供规则层硬编码 / RAG）

> 这三张表不是「OCR 识别契约」，而是「识别出数值后如何判读、触发什么动作」的医学依据。
> **落地建议**：3.1 危急值 → 硬编码后端（触发即弹窗/阻断，零自由发挥）；3.2 分层、3.3 阈值 → 进规则层或 RAG 知识库，供后续单独实现。

### 3.1 危急值表（表1，出现即刻处理）

| 项目 | 触发值 | 立即处理动作 |
|---|---|---|
| 钾 | <3.0 或 >6.0 mmol/L | 室速/室颤风险；心电监护，补钾或降钾 |
| 钠 | <120 或 >160 mmol/L | 意识障碍、抽搐；缓慢纠正 |
| 校正钙 | <1.9 或 >2.9 mmol/L | 手足搐搦、意识改变 |
| 血红蛋白 | <70 g/L，或 24h 内降 >20 g/L | 活动性出血；输血、停抗栓、查出血点 |
| 血小板 | <20×10⁹/L | 自发出血；停 DAPT，必要时输注 |
| 肌酐 | 48–72h 升高 ≥26.5 µmol/L 或 ≥1.5×基线 | 对比剂相关 AKI；停肾毒性药、水化 |
| INR（用华法林者） | >4.0 | 停/减华法林，必要时维生素 K |
| 纤维蛋白原 | <1.0 g/L | 出血倾向；冷沉淀或纤维蛋白原 |
| QTc | >500 ms，或较基线增 >60 ms | 尖端扭转型室速；停 QT 延长药、补钾镁 |
