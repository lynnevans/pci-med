# PCI 术后用药管理 AI 智能体（pci-med）

> **一句话简介：** 面向**基层 / 下级医生**的 PCI 术后长期用药管理 AI 智能体——用**规则引擎 + RAG 指南问答 + Qwen-VL 化验单 OCR** 三大能力，把指南与专家共识"翻译"成基层医生可落地的用药决策支持。

本项目聚焦 PCI（经皮冠状动脉介入治疗）术后患者的**长期用药管理**场景：双抗时程、降脂达标、抗栓-抗凝协调、合并症用药、化验单判读与危急值预警。所有结论均**可追溯至指南出处（Tier 分级）**、**关键数值逐字照抄**、**红线与危急值优先于一切建议**，在"AI 赋能"的同时把自由发挥与幻觉风险压到最低，契合医疗场景的合规要求。

## 技术架构

前后端分离：**Vue 3 前端** 负责交互与表单，**FastAPI 后端** 编排三大智能模块；规则引擎与 RAG/OCR 模型均部署在后端，向量模型（bge-m3）与向量库（ChromaDB）本地化，生成与识别分别走 DeepSeek 与阿里云百炼 Qwen-VL。

## 核心功能

### 模块一 · 智能用药分析（`POST /api/analyze`）

面向 PCI 术后长期管理的**确定性决策核心**，由 `rule_engine.py` 与 `report_builder.py` 实现：

- **人群标签自动计算**：高出血风险（TAG-BR）、高缺血风险（TAG-IR）、老年（TAG-EL）。
- **红线库（13 条）硬拦截**：如术后 <12 个月拟停抗血小板、三联抗栓叠加 >6 个月、剂量越界、氯吡格雷+奥美拉唑、红旗症状、颅内出血史等——命中即优先转诊/阻止，绝不进入 LLM。
- **危急值库（13 项）即报即处理**：血钾、血钠、校正钙、血红蛋白、血小板、肌酐(AKI)、INR、纤维蛋白原、QTc、心率、hs-cTnT+胸痛、二氧化碳结合率、血糖等数值越界即刻预警。
- **常规规则表（55 条，14+ 个域）**：覆盖抗血小板、调脂、抗缺血/心脏保护、合并症协调、随访监测、用药行为、出血处理、临时用药干扰、下转衔接、血压协同、老年、ADR 判读、降压药不良反应等。
- **冲突消解**：内置规则优先级（如 ≥80 岁降压目标放宽覆盖常规 140/90 规则）。
- **输出**：`report_builder` 按《分析结果报告输出模板 V1.0》生成结构化八部分报告，并附**免责声明**。

### 模块二 · RAG 指南问答（`POST /api/chat`，SSE 流式）

面向基层医生的**指南溯源问答**：

- 本地 **bge-m3** 将问题向量化，在 **ChromaDB** 中召回最相关的指南知识块（Top-K）。
- **DeepSeek** 基于召回片段生成答案，严格遵守"摘录式"约束：先给明确结论、再贴原文依据、关键数值逐字照抄、不同指南差异并列呈现。
- 每条答案标注**来源编号 [n] 与指南 Tier（1/2/3）**，医生可逐条核对依据，杜绝幻觉。

### 模块三 · OCR 化验单识别（`POST /api/ocr`）

面向基层"看不懂/看不快"化验单的**识别与回填**：

- **Qwen-VL 系列（qwen3-vl-plus）** 视觉识别化验单 / 心电图，原样读出检测项、数值、单位、参考范围、异常箭头，不做任何医学判断。
- 识别结果经 **`ocr_map.py` 确定性字典映射**直接回填前端表单字段；未命中字典、单位不一致或仅提示项，转交医生人工处理——**映射零 LLM**，避免识别误差被模型二次放大。

## 安装与运行

### 环境要求

- **Node.js** ≥ 18（推荐 20+，前端使用 Vite 8）
- **Python** 3.12（项目 `runtime.txt` 指定 `python-3.12.4`）
- 两个 API Key：
  - `DEEPSEEK_API_KEY`：RAG 问答的生成模型（DeepSeek）
  - `DASHSCOPE_API_KEY`：OCR 识别（阿里云百炼 Qwen-VL）

> 注意：RAG 依赖**本地向量模型** `backend/models/bge-m3` 与**向量库** `backend/vector_db`，以及 `backend/.env` 中的密钥。向量库需先由 `pdf_to_chunks.py` / `vectorize_chunks.py` 从指南 PDF 构建，并用 `add_tier.py` 补全 Tier 标签（见仓库 `backend/` 下脚本）。

### 1. 配置后端密钥

在 `backend/.env` 中填入：

```ini
DEEPSEEK_API_KEY=你的DeepSeek密钥
DASHSCOPE_API_KEY=你的阿里云百炼密钥
```

### 2. 启动后端（FastAPI，端口 8000）

```bash
cd backend
python -m venv venv
# Windows 激活：  venv\Scripts\activate
# macOS/Linux 激活：source venv/bin/activate

pip install -r requirements.txt

# 开发模式（支持热重载）
uvicorn api:app --reload --port 8000

# 局域网 / 评审演示（其他电脑访问 http://<本机IP>:8000）
uvicorn api:app --host 0.0.0.0 --port 8000
```

### 3. 启动前端（开发态，前后端分离）

```bash
cd frontend
npm install
npm run dev      # 默认 http://localhost:5173
```

> 开发态下，前端所有 `/api/*` 请求由 Vite 自动代理到 `http://127.0.0.1:8000`，无需额外跨域配置。

### 4. 生产 / 评审单端口部署（推荐演示方式）

```bash
cd frontend
npm run build    # 产物输出到 frontend/dist

# 回到 backend 目录，重启后端：
cd ../backend
uvicorn api:app --host 0.0.0.0 --port 8000
```

构建完成后，FastAPI 会自动托管 `frontend/dist`，**其他电脑只需访问 `http://<本机IP>:8000` 一个地址**即可使用全部功能（分析 / 问答 / OCR），无需再开 5173 端口。可用 `GET /api/health` 自检连通性与前端是否已构建。

## API 接口

| 方法     | 路径             | 说明                                                               |
| ------ | -------------- | ---------------------------------------------------------------- |
| `GET`  | `/api/health`  | 连通性自检，返回 `{"ok": true, "web": true/false}`                       |
| `POST` | `/api/analyze` | 智能用药分析：传入患者字段，返回标签 / 红线 / 危急值 / 分域建议 / 结构化报告                     |
| `POST` | `/api/chat`    | RAG 问答（SSE 流式）：传入 `{"question": "..."}`，返回溯源片段 + 逐段答案            |
| `POST` | `/api/ocr`     | 化验单识别：传入 `{"image_base64": "...", "card_hint": "血脂"}`，返回识别项与字段映射 |
