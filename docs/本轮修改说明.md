# 本轮修改说明（按“其他修改建议(3).doc” + 精简报告 HTML）

> 本轮目标：修正表单错误、精简检查项、补日期与再住院、把输出改成“精简报告优先 + 详细报告补充”、增加医生登录/注册、Web 标题标注“专为基层医生使用”。

---

## 1. 表单与字段修正

### 1.1 病变支数与干预血管

文件：[`frontend/src/AppV2.vue`](../frontend/src/AppV2.vue)

- 单支：LAD / LCX / RCA 最多勾选 **1** 条；
- 双支：最多 **2** 条；
- 三支：最多 **3** 条；
- **左主干单独列出**，不纳入单/双/三支计数，可与其它血管病变同时存在；
- 勾选超过上限会立即取消并提示；提交前 `validateStep(0)` 再校验一次；
- 每条血管仍分别填写“药物洗脱支架 / 药物球囊 / 可吸收支架”，至少一条 >0。

### 1.2 心律失常

- 心电图卡片先显示“有无心律失常”开关；
- 只有开关为“有”时，才显示“心律失常类型”输入框；
- OCR 若直接给出心律失常类型，会自动把“有无心律失常”置为有。

### 1.3 慢性心衰

- 合并症“心力衰竭”改为 **慢性心力衰竭**；
- 保留 EF 值输入；报告中的合并症名称同步改为“慢性心力衰竭”。

### 2.1 凝血功能

只保留两项，按要求排序：

1. 国际标准化比值（INR）
2. D-二聚体

PT、APTT、TT、纤维蛋白原从录入界面删除。  
INR >3 且未到危急值时进入“需关注异常”；D-二聚体 >0.5 mg/L 进入“需关注异常”。危急值仍由原规则引擎判断。

### 2.2 肝功能

只保留 **ALT / AST** 两个输入，胆红素、白蛋白不再显示。  
后端/前端按 ALT、AST 最大值推导：

- ≤40 U/L：正常
- >40 U/L：轻度升高
- >120 U/L：重度升高

> 40/120 是通用近似阈值，具体以本实验室参考范围为准；报告会提示“按本实验室参考范围判断”。

### 2.3 血脂

- 删除高密度脂蛋白胆固醇（HDL-C）；
- 保留：基线 LDL-C、本次 LDL-C、TC、TG；
- “本次 LDL-C”用于判断是否达标（超高危 <1.4，极高危 <1.8 mmol/L）。

### 2.4 PCI 术后再住院

在“合并症与既往史”列表底部新增：

- PCI 术后是否再住院（开关）
- 住院时间（日期）
- 住院原因（文本）

勾选后为条件必填；详细报告会显示再住院时间与原因。

### 2.5 确诊/发生日期

每一种合并症和既往史勾选后都出现日期行：

- 合并症：**确诊时间**
- 既往史：**发生日期**
- 选择日期后自动显示“距今 X 年 / X 个月”

覆盖：高血压、房颤、慢性心衰、糖尿病、高脂血症、COPD、哮喘、肝功能异常、慢性肾病、既往心梗、既往脑梗死、颅内出血史、消化道溃疡/出血史。

## 2. 输出报告

### 2.1 精简报告（结果页最前面）

新增组件：[`frontend/src/components/ConciseReport.vue`](../frontend/src/components/ConciseReport.vue)

严格按 `PCI术后随访报告精简模板(1).html` 的区块：

1. 报告头：患者姓名、性别/年龄、术后月数、手术日期、复查日期、报告编号；
2. 风险徽章 **只出现 1 个**，并附“危急值/关注异常/用药调整”依据；
3. 一句话结论：动作 + 时限（20–40 字）；
4. 红灯：今天必须处理；无则显示“无”；
5. 黄灯：本次复诊办完；
6. 用药调整一览：现方案、建议方案、处理、理由；
7. 异常指标速览：只列异常，正常不出现；
8. 绿灯：只排本次之后的术后节点（3–4 个），已过去的不显示；
9. 患者提醒卡：立即急诊 / 尽快复诊 / 不要自行做的事；
10. 页脚：依据指南、生成时间、复核医生签名位。

临床动作不再用省略号截断；只对“一句话结论”和患者卡做长度约束。  
打印/导出 PDF 时只打印精简报告，详细报告自动隐藏。

### 2.2 详细报告（补充折叠区）

文件：[`frontend/src/components/AnalysisReport.vue`](../frontend/src/components/AnalysisReport.vue)

按文档 3.2 整改：

- 删除“正常指标确认”整块；
- 信息缺口只列“缺少什么”，不再逐条展开影响/动作；
- 编号改为连续：3.1/3.2/3.3、4.1/4.2/4.3、5.1/5.2，不再出现 5.x→6.x→7.x 跳跃；
- 所有分析、建议、表格不再显示规则编号、来源编号、依据列；
- 参考指南只在最后“依据与说明”出现，只列指南名称；
- 随访只保留本次之后的节点，已过去的节点不再出现；
- 详细报告保留证据、影响、建议、时限，作为精简报告的补充。

## 3. 医生登录 / 注册

### 3.1 后端

新增 [`backend/auth.py`](../backend/auth.py)：

- SQLite `backend/users.db`，已加入 `.gitignore`；
- 密码 PBKDF2-HMAC-SHA256，16 字节盐，120000 次；
- 登录后发 HttpOnly Cookie `pci_session`，有效期 7 天；
- 数据库只存 token 的 SHA-256；
- 注册校验：用户名 3–32 位中英文/数字/下划线，密码至少 6 位；
- 用户名唯一，重复注册会提示。

`backend/api.py` 新增：

- `POST /api/auth/register`
- `POST /api/auth/login`
- `GET /api/auth/me`
- `POST /api/auth/logout`
- 中间件保护除健康检查和登录注册外的所有 `/api/*`；未登录返回 401。

### 3.2 前端

新增 [`frontend/src/components/LoginView.vue`](../frontend/src/components/LoginView.vue)：

- 登录 / 注册切换；
- 注册含姓名/科室（选填）、确认密码；
- 登录后才能进入表单；
- 右上角显示当前医生，可“退出”；
- 草稿按医生用户名分开存储（`pci-med-draft-v4:<username>`），避免同一浏览器不同医生串数据。

## 6. 需要注意

1. ALT/AST 的 40/120 是通用近似阈值，不同实验室参考范围不同；报告已提示按本实验室范围判断。
2. D-二聚体 >0.5 mg/L、INR >3 的“关注”阈值也是常用参考值，具体以本院为准。
3. 精简报告的“一句话结论”由当前最高优先级动作自动生成，不是人工撰写；需要医生复核。
4. 详细报告保留的信息比精简报告多，但已去掉规则编号/来源编号/正常指标确认。
5. 登录账号存本机 SQLite，没有邮箱找回/短信验证；忘记密码需要管理员在数据库层处理。
6. 公开部署时仍建议加 HTTPS 反向代理；医生账号密码不要通过聊天/公开链接传播。
